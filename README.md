# 新笔文学社 · 基础版本 v0.1

岳阳县第二中学「新笔文学社」官网的基础版本。**自包含、零外部依赖**：不接 CDN、不接 Supabase，双击 `index.html` 即可打开。

## 快速开始

- 直接双击 `index.html` 在浏览器打开；或
- 在本目录起一个本地服务（体验更完整）：

```bash
cd xinbi-basic
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 文件结构

```
xinbi-basic/
├── index.html            # 单页站点：幕头/关于/作品/活动/社员/投稿/门户/联系
├── login.html            # 本地演示登录页（不连接真实后台）
├── assets/
│   ├── css/style.css     # 全站样式（宣纸 + 朱砂 + 鎏金，含深色模式）
│   └── js/
│       ├── data.js       # 站点数据：社团信息/作品/活动/社员/门户/联系方式
│       └── app.js        # 交互逻辑：作品渲染/搜索/弹窗/点赞收藏评论/倒计时/表单
└── README.md
```

## 已实现的功能

- **幕头**：逐字标题动画、粒子背景、印章式荣誉标签
- **作品展示**：分类筛选（散文/诗歌/小说/随笔）、关键词搜索下拉、封面由 SVG 自动生成、加载更多、详情弹窗（点赞/收藏/评论，本地持久化）
- **近期活动**：日期按打开时间自动排期，倒计时实时刷新（修正了原站的日期笔误）
- **社员风采 / 文学网站入口 / 联系我们**：数据驱动渲染
- **投稿 / 加入申请**：表单校验 + 本地保存 + 成功反馈
- **全局**：深色模式、阅读进度条、回到顶部、滚动揭示动画、移动端汉堡菜单、响应式布局（最窄 360px）

## 与原站的关系

- 原站源码备份在同级目录 `Xinbi/`（动态版，Supabase 后台 + admin.html）与 `xinbi-literature.github.io/`（静态部署版）。
- 本基础版本**未包含**任何 Supabase 密钥；作品/社员/活动均为本地示例数据，表单与登录为本地演示，清缓存后重置。
